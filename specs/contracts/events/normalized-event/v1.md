# DEX AI Normalized Event Contract v1.0.0

Status: Foundation Candidate — not published.

Stable ID: `urn:dex-ai:contract:event:normalized-event`

## Purpose

A Normalized Event converts one published Raw Event into a deterministic, typed representation. It preserves source lineage and records partial or failed normalization without inventing missing values. It contains no canonical fact, analysis, risk, score, confidence, decision, trade instruction, Agent, or Service behavior.

## Dependencies

- Event Envelope v1.0.0, published and immutable.
- Raw Event v1.0.0, published and immutable.

The envelope must use `event_stage=NORMALIZED`, `provenance.origin_kind=NORMALIZED`, and identify the source Raw Event through `causation_event_id` and the payload lineage fields.

## Foundation event type

This vertical slice authorizes only `MINT_INITIALIZED`. Later normalized event types require their own explicit contract work and are not implicitly authorized.

## Payload fields

| Field | Type | Required | Rule |
|---|---|---:|---|
| `normalization_status` | closed enum | Yes | `SUCCESS`, `PARTIAL`, or `FAILED`. |
| `source_raw_event_id` | event URN | Yes | Must equal envelope `causation_event_id`. |
| `source_raw_payload_ref` | raw artifact URN | Yes | Immutable source artifact reference. |
| `normalizer_name` | bounded safe string | Yes | Deterministic normalizer identity. |
| `normalizer_version` | SemVer string | Yes | Exact normalizer version. |
| `normalization_profile` | DEX AI URN | Yes | Versioned rule profile. |
| `normalized_event_type` | closed enum | Yes | Foundation slice: `MINT_INITIALIZED` only; must equal envelope `event_type`. |
| `normalized_entity_refs` | unique URN array | Yes | Entities derived without canonical adjudication. |
| `normalized_data` | closed object or null | Yes | Typed mint data; null only for `FAILED`. |
| `field_lineage` | closed record array | Yes | Source JSON pointer and transformation for every emitted normalized field. |
| `normalization_warnings` | closed record array | Yes | Missing or ambiguous source information. |
| `normalization_errors` | closed record array | Yes | Deterministic normalization failures. |
| `source_schema_ref` | safe string or null | Yes | Source schema identity when known. |
| `normalization_started_at` | UTC microsecond timestamp | Yes | Start of normalization. |
| `normalization_completed_at` | UTC microsecond timestamp | Yes | Completion, not before start. |

## Invariants

1. `SUCCESS` requires data, lineage, and no errors.
2. `PARTIAL` requires data and at least one warning or error.
3. `FAILED` requires null data and at least one error.
4. Missing values are never guessed; uncertainty is explicit.
5. Every emitted field has source lineage.
6. Normalization does not create a Canonical Fact or authorize any downstream contract.
7. Published dependency artifacts and their digests remain unchanged.
