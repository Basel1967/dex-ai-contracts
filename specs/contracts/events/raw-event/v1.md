# DEX AI Raw Event Contract v1.0.0

Status: Foundation Candidate — publication gate independent and closed pending verification.

Stable ID: `urn:dex-ai:contract:event:raw-event`

## Purpose

A Raw Event preserves exactly what a source delivered plus capture metadata. It contains no analysis, risk, score, confidence, decision, canonicalization, or semantic repair.

## Dependency

Every Raw Event is carried by the immutable published `Event Envelope v1.0.0`. The envelope bytes and semantics are not changed by this contract.

## Payload fields

| Field | Type | Required | Rule |
|---|---|---:|---|
| `capture_method` | closed enum string | Yes | Must equal envelope provenance collection method. |
| `request_or_subscription_ref` | non-empty string | Yes | Safe opaque request/subscription reference; no credential material. |
| `source_endpoint_or_stream` | safe URI string | Yes | `https`, `wss`, or namespaced `urn`; user-info and secret-bearing queries forbidden. |
| `source_received_at` | UTC RFC3339 microsecond timestamp | Yes | Must not be later than envelope `observed_at`. |
| `http_or_transport_metadata` | closed object or null | Yes | Transport metadata only; no unrestricted headers. |
| `raw_content_type` | closed enum string | Yes | `application/json` or `application/octet-stream`. |
| `raw_payload_ref` | raw artifact URN | Yes | Must equal envelope `raw_ref.artifact_id`. |
| `raw_content_hash` | SHA-256 string | Yes | Must equal envelope `raw_ref.content_hash`. |
| `collector_clock` | closed object | Yes | Clock source, capture time, and non-negative uncertainty in milliseconds. |
| `collection_attempt_id` | collection-attempt URN | Yes | Immutable identifier for the capture attempt. |
| `source_cursor_or_checkpoint` | bounded string | Conditional | Present only when the source supplies a cursor/checkpoint. |
| `redaction_manifest` | array of closed records | Conditional | Required and non-empty when lawful/safety redaction occurs; otherwise may be empty. |

## Invariants

1. Raw content is immutable and referenced by digest.
2. Parsing failure never deletes the Raw Event.
3. Collector metadata is structurally separate from source content.
4. Credentials, secrets, authorization headers, cookies, tokens, and unnecessary private data are prohibited.
5. Replay under the same normalizer version must consume the same referenced raw bytes.
6. The contract cannot emit or authorize a trade, Agent, Service, score, risk, confidence, or decision.
