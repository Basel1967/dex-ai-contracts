# ADR-0002: Event Envelope semantic closure

Technically accepted on 2026-08-23 by project owner Basel Atta for a single-owner development project. Exact types, identifiers, UTC microsecond timestamps, ordering, SHA-256 canonical payload hashing, immutable raw references, closed enums, replay cutoff and fail-closed admission are defined by schema 1.0.0 and the contract specification. This does not claim independent approval or publication. MSR-011 remains open because the base-image digest could not be registry-verified in this execution environment.
